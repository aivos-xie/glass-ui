# 材质与交互

[简体中文](materials-and-motion.md) | [English](../docs/en/materials-and-motion.md)

## 分层

从后往前：有变化的场景背景 → 背景处理层 → 半透明染色层 → 厚度/投影 → 细边缘高光 → 指针光斑 → 内容和焦点。背景处理层与内容是兄弟，不在内容祖先上使用 `filter`。所有装饰设 `pointer-events: none`、`aria-hidden="true"`。

玻璃需要透出背景：纯白底上的透明白卡片会缺乏材质线索。优先利用现有背景；展示页可放静态柔和色团，不必给业务页面强加渐变球。装饰不能盖过信息层级。

滚动后的组件同样需要底景：避免用固定高度的首屏装饰承载整页玻璃。可选固定静态背景或分区底景，并在面板切换、增减内容后复查覆盖范围。背景只给出明暗与色彩线索，前景文字保持清晰、不透明。

## 预设起点

| 材质 | 用途 | 浅色表面 alpha | blur | 边缘与折射 |
| --- | --- | --- | --- | --- |
| 轻玻璃 | 输入、小按钮、选项轨道 | .18–.38 | 8–12px | 细边，默认无位移 |
| 磨砂 | 面板、卡片、菜单 | .35–.60 | 16–24px | 柔光，少量内高光 |
| 清透液态 | 共享胶囊、开关滑块 | .16–.35 | 3–8px | 边缘厚度，可选局部折射 |
| 染色 | 主按钮、标签、选中态 | .15–.30 的品牌色 | 12–20px | 保持文字对比，状态带图形标记 |
| 棱镜 | 强调组件边缘 | 与清透相同 | 与清透相同 | 很窄的彩色边缘；不能整片彩虹 |

深色模式单独设 surface、ink、muted、border、shadow，不只是翻转背景。以上是调参起点，不是强制样式。`assets/demo/glass.css` 的 tokens 可直接覆盖。

明显玻璃感的深色展示可从下列参数调起；它们不是业务界面的统一配色要求：

| 层 | 深色展示起点 | 调整重点 |
| --- | --- | --- |
| 页面与磨砂面板 | 底色如 `#0d111e`；深蓝灰表面 alpha .40–.48，例如 `rgba(29,36,56,.44)`；blur 16–18px | 留出可见底景，同时测量文字对比 |
| 选项轨道 | 透明白 alpha .04–.08；blur 6–10px | 比选中项更安静，不重复厚磨砂 |
| 共享选中胶囊 | 透明白或浅色调 alpha .06–.13；blur 3–5px | 窄上缘高光、轻下沿阴影；不要白色实心填充 |
| 面板内按钮与标签 | 透明填充，blur 0–4px | 用细边和状态区分，不再次覆盖强磨砂 |

例如轨道 9px、胶囊 5px、内部按钮 3px，可与外层 18px 磨砂区分。边框 alpha 可从 .20–.30、窄上缘高光 .40–.60 起步；高光保持有方向，强度以实际背景为准。材质切换时将磨砂表面覆盖限定到对应主题与材质，避免一条全局深色 surface 覆盖清透、染色和棱镜预设。

若界面像白块或灰塑料，依次检查底景是否存在、叠层填充是否过浓、重复 blur 是否抹平背景、边缘是否整圈等亮。先降低无用叠层和恢复底景，再微调高光；不要只增加 blur 或整体发光。

条纹/压纹、水波和 3D 水晶属于进阶预设：只在用户请求时加定制位移贴图或 WebGL 材质，并说明需要额外实现；随附 demo 不声称已经提供这些效果。

## 指针卡片

固定外层 `[data-glass-card]` 接收 `pointermove`，读取它的 rect；可变内层 `[data-glass-face]` 执行 transform。先批量读布局，再写 CSS 变量，避免反复读写布局。通过 ResizeObserver、滚动或下一次有效事件刷新测量。页面静止时停止 RAF。

设相对中心的归一化位置为 `u,v ∈ [-1,1]`，映射 `rx=-v, ry=u`。限制合成角而非仅限制单轴：设最大角 `m=4π/180`，`a=abs(rx*m), b=abs(ry*m)`；将向量约束到半径 `m`，再用 `acos(cos(a)*cos(b))` 检查实际法向偏转角。控制器示例还做一次比例收缩，使四角也满足 4°。

用时间相关平滑 `a = 1 - exp(-dt/τ)`，避免不同刷新率改变手感。默认倾斜 τ≈70ms，复原 τ≈100ms，约 350ms 内接近静止。移出、`pointercancel`、失焦、页面隐藏都清零目标；`prefers-reduced-motion` 变化时立即复原。粗指针设备不启用跟随倾斜。

光斑约 160px，alpha 从 .08–.16 起；浅色表面难辨时先检查底景与表面填充，再调整光斑色调或强度。边框追光仅通过掩膜作用于约 1px 的窄环带。不能用全卡 `box-shadow` 冒充局部边缘追光。掩膜不支持时保留普通细边框。

## 共享选中胶囊

胶囊为单一绝对定位层，按钮/文字另占一层。选项的实际宽度和位置决定静止目标，不硬编码等宽。使用轨道内容坐标，考虑边框、内边距、横向滚动。

示例采用左右两条边的弹簧：向右时右边刚度略高、左边略低；向左时相反。速度相关延伸限制为目标宽度的约 12%，微小高度压缩仅应用于背景层。弹簧用秒级时间步计算；大帧间隔限幅，避免后台恢复时跳飞。到位收敛阈值控制位置误差 ≤.35px；框架实现也可用已有 Motion spring。

连续点击不得取消后重新从旧选项动画：新目标接管当前两边位置和速度。尺寸变化时重测并立即对齐，减弱动态时直接对齐。拖动是可选增强，不能取代 click 与键盘操作；示例基线支持点击、键盘、按下膨起，不包含拖拽切换。

## 折射增强

`backdrop-filter: blur(...)` 为基础。示例的增强模式为 `backdrop-filter: url(#...) blur(...)`：SVG `feImage` 提供按圆角距离生成的 RG 位移图，`feDisplacementMap` 只在边缘改变背景采样。

- RG 中点约 128 表示零位移，靠近弧边沿法线改变 RG；中心仍近乎中性。
- 使用 `color-interpolation-filters="sRGB"` 与生成贴图一致，避免中性值在颜色空间转换后偏移。
- 位移图尺寸随真实组件尺寸更新；实例 ID 唯一，适应多个独立胶囊。
- 这种 SVG 位移是视觉近似，不是光学模拟；棱镜 CSS 边线也不等于真实 RGB 分通道色散。需要真实色散时使用合适 shader/库并单独验证。
- `CSS.supports` 只判断语法。用户明确开启增强后仍需用带文字、网格的背景做截图比较；不成功立即用基础层。
- 不对文本节点或按钮容器应用普通 `filter: url(...)`，否则前景会一起变形。

在减少动态效果时禁用膨起、位移和弹性。`forced-colors` 使用系统色的实边框和选中标记。无 backdrop 支持时增加表面不透明度，保持结构完整。

指定图片的普通 SVG 滤镜路线与任意 DOM 的 backdrop 路线分开，见[渲染与性能](rendering-and-performance.md)。纵向胶囊沿纵轴应用同一前后缘逻辑；前景文字仍不变形。增加对比度或减少透明度时使用稳定实色底并停用位移，不能只降低动画速度。

基础材质不要依赖对未知 `prefers-reduced-transparency` 特性的否定查询才能显示。先提供可用的基础样式，再在支持的正向 `reduce` 条件下覆盖为实色；同时保留显式 `data-glass-transparency="reduced"`、静态质量和无模糊路径。检查级联优先级，避免后加载的渐变、阴影或滤镜重新盖住回退。强制颜色使用系统色；与减少透明度同时生效时也不能被自定义实色覆盖。
